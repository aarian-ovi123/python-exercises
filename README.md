# Python Exercises

Python exercises from my programming class.

## Exercises:

- **Hello, World! (CQ)** – Reads how many messages there are, then prints each message back exactly as typed. A Code Quest practice problem.
- **Infotainment System** – Simulates a car's dashboard screen. It decides what to show based on the gear, voice commands and screen taps, and the backup camera always takes priority when the car is in reverse.
- **Adding to a Value** – Adds a number the user types to a built-in value of 10, with comments showing which variables are global and which are local.
- **Area of a Square** – Calculates a square's area from the side length the user types, using a default of 10 if the input is 0, negative or not a number.
- **Print Multiple Times** – A function that prints a message as many times as you tell it to.
- **Print Product** – A function that multiplies two numbers and prints the result.
- **Weather** – Suggests footwear (sandals, galoshes or boots) based on the weather the user types.
- **Category** – Collects three categories from the user, three items each, and prints each category with its items.
- **Rolling Dice** – Prints all 36 possible combinations of rolling two dice.
- **Higher / Lower** – A guessing game that tells you if your guess is too high or too low until you find the magic number.
- **Higher / Lower 2.0** – The same game with a decimal number, where your guess only has to be correct to 2 decimal places.
- **How Many Names?** – Asks how many names you have, collects each one and prints your full name.
- **Average Test Score** – Averages three test scores the user enters.
- **Counting 10 to 100 by Tens** – Prints 10, 20, 30… up to 100 using a loop.
- **Divisibility** – Checks whether one number divides evenly into another, and keeps asking until the denominator isn't zero.
- **2 Through 20** – Prints the even numbers from 2 to 20 using a while loop.
- **Food Portions** – Splits food evenly among a group and checks the amount you took, comparing rounded decimals so tiny rounding errors don't break it.
- **School Key** – Tells you whether you can have a school key based on your role, using the `or` operator.
- **Reservation** – Checks whether your name matches the name on a restaurant reservation.
- **Positive, Negative, or Zero?** – Tells you whether the number you enter is positive, negative or zero.
- **Old Enough To Vote?** – Checks whether you're old enough to vote in the U.S. based on your age.
- **Is It Raining?** – Uses a True/False variable to decide whether to dance in the rain or the sun.
- **Plants** – Uses True/False variables to track whether a plant needs water or repotting.
- **Rectangle** – Calculates a rectangle's area and perimeter, showing the formula for each.
- **Rectangle, Part 2** – Prints the area and perimeter with labels, using string concatenation.
- **Rectangle, Part 3** – Lets the user type the length and width, then prints the area and perimeter.
- **Introduction** – Practices string and integer variables by printing a short profile.
- **Introduction, Part 2** – Prints a one-line greeting with a name and age stored in variables.
- **Age** – Asks your age and tells you how many birthday candles you'll need.
- **Hello, <name>** – Asks for your name and says hello.
- **Vertical Name** – Prints a name vertically, one letter per line.
- **Transaction** – Simulates a bank deposit or withdrawal from a $1000 balance, rejecting invalid amounts and overdrafts.
- **Presidential Eligibility** – Checks age, citizenship, birthplace and residency, then lists every reason someone isn't eligible to run for U.S. president.
- **Recipe for Salad** – Scales three salad ingredients to any number of servings.
- **Get Ready For School!** – Walks through a morning routine using functions, including default parameter values.
- **Test Study Program** – Simulates studying for a test, repeating study cycles until no weak spots are left.
