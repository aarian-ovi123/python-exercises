# Python Exercises

Python exercises from my programming class.

## Exercises:

- **Hello, World! (CQ)** – Reads how many messages there are, then prints each message back exactly as typed. A Code Quest practice problem.
- **Infotainment System** – Simulates a car's dashboard screen. It decides what to show based on the gear, voice commands and screen taps, and the backup camera always takes priority when the car is in reverse.
